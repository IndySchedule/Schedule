# Student Chromebook usability test

Run this with five students on school-managed Chromebooks. Do not collect names, emails, class schedules, or recordings unless the student and school have explicitly approved it.

## Test setup

- Use a fresh Chrome profile or clear Indy Schedule site data before each session.
- Give each student the site URL and this goal: “Set this up so it shows your school day the way you want.”
- Do not explain where controls are. Ask the student to think aloud.
- Record only task completion, time, confusion points, and the student’s optional comments.

## Tasks

1. Complete welcome setup using guest mode or a test account.
2. Change today to Late Start, then return it to Automatic.
3. Choose a palette, use Undo, and enable Follow device appearance.
4. Open Today at Indy and find the source for a calendar event or lunch information.
5. If using a test account, change a setting, open the site on a second Chromebook, and confirm it syncs.
6. Turn Wi-Fi off temporarily and confirm the bell schedule still opens.

Afterward ask: “What did you expect to happen that didn’t?” and “What would you change first?” Fix repeated problems before isolated preferences.
